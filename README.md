### Installation — macOS

1. Download and unzip the file, then drag the app into the **Applications** folder.
2. On first launch, if macOS says the app cannot be opened, go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. Enter your serial key, tick the License Agreement checkbox, and click **Activate**.

**Requirements:** macOS, Intel or Apple Silicon. On Apple Silicon Macs, macOS may ask to install Rosetta 2 on first launch — click **Install**.

### Installation — Windows

1. Download `OptiBarrel_Setup.exe` and double-click it.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**.
3. Follow the installer. When it finishes, open OptiBarrel from the **Start** menu.
4. Enter your serial key, tick the License Agreement checkbox, and click **Activate**.

**Requirements:** Windows 10 or 11 (64-bit).

### Sample File

OptiBarrel includes a sample lens (Double Gauss). Open it from **Help → Open Sample Lens** to try the software.

### 安装 — macOS

1. 下载并解压，把程序拖到 **应用程序（Applications）** 文件夹。
2. 第一次打开时，如果 macOS 提示无法打开，请到 **系统设置 → 隐私与安全性**，点击 **仍要打开**。
3. 输入序列号，勾选同意许可协议，点击 **激活**。

**系统要求：** macOS，Intel 或 Apple 芯片均可。Apple 芯片的 Mac 首次打开时，系统可能会提示安装 Rosetta 2，点击 **安装** 即可。

### 安装 — Windows

1. 下载 `OptiBarrel_Setup.exe`，双击运行。
2. 如果出现 **"Windows 已保护你的电脑"**，点击 **更多信息 → 仍要运行**。
3. 按安装向导完成安装，之后从 **开始** 菜单打开 OptiBarrel。
4. 输入序列号，勾选同意许可协议，点击 **激活**。

**系统要求：** Windows 10 或 11（64 位）。
